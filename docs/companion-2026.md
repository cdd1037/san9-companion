<a id="decisions"></a>
## 采用原则

| 标记 | 含义 |
| --- | --- |
| 内置 | 本体固定行为，无玩家选项 |
| 可选配置 | 玩家可选择启停、数值或预设 |
| 不采用／暂缓 | 当前不实施，不据此新增选项或验收要求 |
| 已覆盖／部分覆盖 | 仅描述指定能力，具体差异另行取舍 |
| 未立项／覆盖未核 | 尚无采用决定或专项核对，不代表缺陷 |
| 近似实现 | 插件与伴侣本体不完全相同，不表示remake状态 |

每项决定只约束明确行为。“建议内置／可选”不等于已批准；暂缓或不采用的玩法项保留决定及理由，避免重复立项。自研AI试验与伴侣规则分别评估，具体约束以[remake采用规格](../../remake/specs/original-ai/behavior.md)为准。

<a id="implementation"></a>
## 实现与局中配置

规则面板按“辅助→势力→成长→计略→兵法→攻防→设施舰船→阵亡→俘虏”分页，兵法页分发动、联动、效果三组。宿主配置独立保存，不随战局存档；关闭面板时仅保存并应用实际变更，新游戏读取有效配置。

沿用内容定义、Core结算、Application规划、界面草稿与提交的职责。预览、命令验证和结算共用领域规则；AI读取快照生成计划，经公共准备预留资源，提交消费一次，失败释放未提交预留。威胁、需求、容量、在途承诺和优先级分别建模，内部配额不自动成为玩家选项。

| 设置类别 | 生效边界 |
| --- | --- |
| 显示、快捷键与报告 | 即时或下一次刷新 |
| AI策略候选 | 若采用，在下一次完整规划生效；保留已提交命令，失效未提交计划与派生缓存 |
| 成功率、成长、伤害与经济系数 | 下一次相应判定／结算；不追溯重掷已确定结果 |
| 容量与人数约束 | 校验现有世界后生效；不容纳既有状态时拒绝，或按明确规格迁移，不悄悄截兵 |
| 地图、对象结构与身份定义 | 新会话／新局，局中迁移须有专项规格 |

配置使用统一模型与明确校验，加载失败须报告原因，不静默替换用户选择。新建与恢复时校验内容和世界状态的一致性。新增随机判定纳入确定性随机流管理，不假定其不影响原随机消耗。

世界、AI冷却、承诺和随机状态随会话恢复。具体规则的生效点以采用规格为准。验证覆盖适用方、触发点、数值例、公共命令、资源守恒、容量和存读档；AI强弱还须验证可执行计划及战役效果。

## 范围与依据

清单保留与san9-remake有关的玩法、策略、交互及实现约束；排除外部注入工具能力、插件引导加载、原版控件盘点、原版专属崩溃／初始化修复和已明确不纳入迁移的外部都市配置。相关原作事实仍见[算法参考](optimizations.md)、[恢复资料](../recovery/README.md)及原始帮助，不另建待办。

编号沿用原清单，删除条目后不重排。插件设置源表共127项，本页保留126项（排除105），其中已接入45项；N类保留54项，E类保留26项。三类存在交叉，不能相加为功能总数。插件新增机制与原伴侣行为分别标明。

依据包括2026恢复代码与样本、39r插件源码、原游戏IDA主库、帮助／更新说明和remake实现／规格。“代码／静态已核”表示有实现依据，“记录／历史”表示有作者或旧版资料；后者不自动证明2026精确规则，静态分析也不证明长期AI效果。
